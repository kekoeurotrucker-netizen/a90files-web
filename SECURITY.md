# Seguridad — A 90 Files

La seguridad y la privacidad tienen prioridad en A 90 Files.

## Contacto

Para informar de una vulnerabilidad, escribe a **a90files@gmail.com**.

No publiques secretos, tokens, credenciales, datos personales ni detalles explotables en issues públicos.

## Gestión de secretos

- Los secretos OAuth, claves privadas y credenciales administrativas no deben almacenarse en el repositorio.
- Las claves públicas o identificadores diseñados para cliente no deben tratarse como secretos.
- Si un secreto se expone accidentalmente, debe revocarse y regenerarse antes de volver a usarse.
- Las cuentas administrativas deben usar autenticación multifactor siempre que el proveedor lo permita.
