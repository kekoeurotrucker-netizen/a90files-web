VaultPool 1.30.16.0 es la versión pública actual en Microsoft Store

VaultPool Storage MultiTool reúne varias nubes y cuentas en una única experiencia para Windows. La versión 1.30.16.0 incorpora la nueva identidad visual y una revisión profunda de navegación, seguridad y herramientas.

Qué ofrece la versión actual

VaultPool 1.30.16.0 combina gestión multinube, cifrado local, compresión inteligente, redundancia opcional y una biblioteca de archivos con streaming y herramientas de edición.

Mis nubes y trabajo con archivos existentes

Desde Mis nubes puedes explorar carpetas, buscar, ordenar, seleccionar destinos e importar contenido desde las cuentas compatibles. Las importaciones pueden utilizar cifrado, verificación y redundancia opcional.

Multimedia, PDF, texto y código

La biblioteca puede reproducir vídeo y audio por streaming y mostrar imágenes cuando el formato y el proveedor lo permiten. También integra visor y editor de PDF, texto y código, con guardado de cambios como nuevas versiones para no pisar el original.

Seguridad y cuenta

La versión actual muestra la cuenta en cabecera, soporta autenticador, exige una contraseña maestra fuerte para nuevas bóvedas, permite un respaldo cifrado opcional y puede bloquear superficies sensibles tras un periodo de inactividad.

Nueva identidad e idiomas

La interfaz adopta la nueva imagen de VaultPool, con navegación más clara, iconos con nombres y una mejor distribución de archivos, nubes y ajustes. El idioma puede seleccionarse entre español e inglés y la elección permanece guardada.

Descarga oficial

Microsoft Store es la vía pública oficial de instalación y actualización de VaultPool para Windows. Algunas funciones dependen del proveedor conectado, del formato del archivo y del estado de autorización de cada cuenta.
