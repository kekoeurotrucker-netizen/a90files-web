ACTUALIDAD · VAULTPOOL

VaultPool ya tiene su versión pública en Microsoft Store

La aplicación aparece en la tienda como Vault Pool Storage y está publicada por A90Files. Su objetivo es reunir varias cuentas y servicios de almacenamiento en una única experiencia para Windows.

Microsoft StoreWindowsA90FilesUtilidades y herramientas
Abrir Microsoft Store ↗Ver ficha técnica

Una nube virtual formada por varias cuentas

La descripción publicada en Microsoft Store presenta Vault Pool Storage como una aplicación capaz de reunir varias cuentas y servicios de almacenamiento en una única nube virtual. La idea es aprovechar conjuntamente el espacio disponible en los proveedores compatibles que conecte el usuario, sin alterar ni aumentar artificialmente las cuotas de esos servicios.

Biblioteca unificada y gestión centralizada

La versión pública pone el foco en trabajar desde una sola aplicación: consultar capacidad y estado, organizar archivos, buscar contenido y gestionar cuentas y proveedores desde un punto común. La ficha de Store también menciona funciones de salud e integridad para conocer el estado de los datos.

Streaming desde el almacenamiento multinube

Entre las funciones publicadas se incluye la reproducción multimedia por streaming desde la nube unificada. Cuando el formato y el proveedor lo permiten, el contenido puede reproducirse sin tener que descargar previamente el archivo completo.

Procesamiento local y control del usuario

La aplicación está planteada para realizar el procesamiento principalmente en el equipo del usuario y mantener bajo su control la organización, distribución y acceso a los datos. La descripción de Microsoft Store también destaca el control manual de acciones sensibles.

Qué figura ahora mismo en la Store

La ficha pública muestra el nombre Vault Pool Storage, el editor A90Files, la categoría Utilidades y herramientas, clasificación PEGI 3 y una galería de seis capturas de pantalla. La página web de Store consultada no expone un número de versión visible, así que A 90 Files identifica esta edición simplemente como la versión actualmente publicada.

Descarga oficial

La vía pública y verificable en este momento es Microsoft Store. La página de VaultPool y su ficha en A 90 Files enlazan directamente a esa publicación.
