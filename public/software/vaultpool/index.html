VAULTPOOL STORAGE · WINDOWS

Tu almacenamiento.En una sola vista.

VaultPool reúne varias nubes y cuentas en una sola experiencia para Windows. La versión 1.30.16.0 incorpora nueva identidad visual, Mis nubes, dos idiomas, seguridad reforzada, streaming y herramientas integradas para documentos.

Versión pública actual: 1.30.16.0, disponible desde Microsoft Store para Windows x64.

01

Mis nubes

Explora cuentas y carpetas, busca, ordena, selecciona destinos e importa contenido desde una sola interfaz.

02

Seguridad reforzada

Autenticador, contraseña maestra fuerte, respaldo cifrado opcional, bloqueo por inactividad e integridad SHA-256.

Streaming y edición

Vídeo, audio e imágenes, además de PDF, texto y código con guardado como nuevas versiones.

04

Multinube local

Cifrado, compresión inteligente y redundancia opcional manteniendo el control en tu propio equipo.
