AutoMiner.
Minería adaptativa, con margen para tu PC.

AutoMiner es una aplicación local para Windows diseñada para supervisar un minero externo y adaptar su intensidad según temperatura, carga y recursos disponibles. La prioridad del proyecto es la estabilidad y la vida útil del equipo, no exprimirlo al máximo.

ESTADO

Aún sin build pública

AutoMiner sigue en desarrollo. Todavía no hemos publicado una versión para Windows ni existe una descarga oficial.

PRIORIDAD

Cuidar el hardware

La regulación de carga y las paradas de seguridad están planteadas para mantener temperaturas, estabilidad y margen de recursos bajo control.

Modos de trabajo

OFF, ECO, BALANCED y AWAY para distintos niveles de actividad y disponibilidad del equipo.

Carga adaptativa

Ajuste de intensidad según GPU, CPU, VRAM, temperaturas y carga real del sistema.

Convivencia

Reducción de intensidad cuando Premiere, herramientas de IA u otras aplicaciones necesitan recursos.

Seguridad

Parada cuando las condiciones térmicas o del sistema hagan necesario proteger el equipo.

AutoMiner se anunciará como disponible solo cuando exista una build pública realmente preparada para probar. Hasta entonces, su estado seguirá marcado como “Próximamente”.
