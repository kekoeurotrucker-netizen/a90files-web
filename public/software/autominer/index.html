Minería adaptativa.
El hardware va primero.

AutoMiner es una aplicación local para Windows diseñada para supervisar un minero externo y adaptar su intensidad según temperatura, carga y recursos disponibles. La prioridad del proyecto es la estabilidad y la vida útil del equipo, no mantener la minería al máximo a cualquier precio.

ESTADO ACTUAL

Interfaz real en pruebas

El proyecto ya dispone de una interfaz funcional de desarrollo con perfiles de carga, telemetría de hardware, estado del minero y avisos de seguridad. Todavía no existe una build pública para descargar.

PRIORIDAD

Cuidar el hardware

La regulación de carga y las paradas de seguridad están diseñadas para conservar margen térmico y recursos cuando el PC está trabajando en otras tareas.

Perfiles

OFF, ECO, BALANCED, AWAY y opciones manuales para distintos niveles de actividad.

Carga adaptativa

Ajuste progresivo según GPU, CPU, VRAM, temperaturas y margen disponible.

Convivencia

La idea es reducir intensidad si Premiere, herramientas de IA u otras aplicaciones necesitan recursos, sin detenerse siempre por sistema.

Seguridad

Parada cuando la situación térmica o los sensores indiquen que continuar no es conveniente.

AutoMiner sigue marcado como “Próximamente”. No hay instalador ni descarga pública todavía. Cuando exista una build de Windows suficientemente validada, se anunciará aquí y en el foro.
