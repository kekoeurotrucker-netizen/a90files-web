Marea Studio es una aplicación de creación musical local en desarrollo. Permite describir una idea, elegir estilo, voz e idioma y generar música con letra creada por IA, letra escrita por ti o en modo completamente instrumental. Las primeras generaciones reales ya se han completado con un resultado inicial bastante satisfactorio.

ESTADO REAL

Primeras pruebas ya realizadas

Codex verificó una build portable interna de desarrollo 1.3 de 206 MB, 40 pruebas y cinco generaciones musicales reales. La valoración inicial de esas pruebas es bastante satisfactoria.

DISTRIBUCIÓN

Todavía no hay descarga pública

La portable actual es una build interna para probar y seguir desarrollando la aplicación. No se publica ningún archivo todavía. Cuando exista una build preparada para compartir, aparecerá en el Release Center.

Tres modos de letra

Solo instrumental, letra generada por IA desde el prompt o letra escrita manualmente por el usuario.

Voz e idioma

Selección explícita de voz masculina o femenina y español o inglés, con avisos cuando el prompt contradice esos controles.

Producción

Modos rápidos y de mayor cálculo, incluido XL de 64 pasos y un modo de detalle pensado para buscar más calidad.

Escuchar el resultado

Las generaciones completadas muestran su canción y controles de Escuchar/Pausar, con acceso también desde la Biblioteca.

CALIDAD / OBJETIVOMás calidad musical, no solo más resolución de archivo.

El trabajo actual busca mejorar composición y también el carácter de guitarras, batería, bajo, electrónica y voz. La calidad se evalúa escuchando generaciones reales, no por subir los kHz ni por remuestrear el resultado.

Marea Studio continúa en desarrollo. La interfaz se está reorganizando para ser intuitiva y evitar pantallas cargadas de controles. Las funciones y formatos públicos pueden cambiar antes de una primera release.
