VaultPool Storage prepara su próxima actualización

La nueva versión amplía la edición publicada en Microsoft Store con una biblioteca mucho más práctica, manteniendo el mismo principio: los archivos se comprimen, cifran y distribuyen sin modificar el original.

Una biblioteca mucho más práctica

La actualización en preparación lleva VaultPool más allá de la versión pública actual. El objetivo es que la biblioteca deje de ser solo un punto donde ver archivos protegidos y pase a funcionar como un espacio de trabajo real, con organización, reproducción, edición y recuperación sin perder la protección original.

Carpetas protegidas que se pueden explorar

Una carpeta subida ya no se tratará como un ZIP opaco. Aparecerá como Carpeta protegida, se podrá abrir y mostrará sus elementos según su tipo original.

  • Música, vídeos, imágenes y PDFs podrán explorarse directamente desde la carpeta protegida.
  • Cuando se abra un elemento, solo se extraerá temporalmente ese contenido.
  • Los fragmentos almacenados en remoto seguirán cifrados.

Compresión de carpetas con datos reales

El informe de compresión diferenciará claramente el tamaño original de la carpeta, el tamaño del paquete comprimido, el ahorro obtenido y el tamaño final después del cifrado y la distribución.

Buscador, filtros y organización personalizada

La biblioteca incorporará buscador, filtros, ordenación y carpetas personalizadas. Se podrán crear y renombrar carpetas para organizar el contenido de forma independiente a cómo esté distribuido físicamente entre las distintas nubes.

Selección de nubes más clara

La selección de destino se está reorganizando en tres niveles: un selector global para todas las cuentas, un selector por proveedor y selección individual de cada cuenta. El espacio libre, el total y el porcentaje utilizado se mostrarán de forma compacta para facilitar la decisión.

Reintentos automáticos y recuperación del progreso

Las subidas, recuperaciones y borrados reintentarán automáticamente los fallos temporales de conexión. Si el problema persiste, VaultPool conservará el progreso ya confirmado y explicará qué proveedor o cuenta necesita revisión.

PDFs: formularios, firma visual y firma con certificado

El visor de PDF se amplía para permitir rellenar formularios interactivos y guardar una nueva versión cifrada manteniendo editables sus campos.

  • Firma visual con pincel: permitirá dibujar una firma y estamparla en una nueva copia del PDF. Se identificará expresamente como firma visual y no sustituye a un certificado digital.
  • Firma oficial con certificado: VaultPool abrirá AutoFirma utilizando los certificados disponibles en Windows. La clave privada y el PIN no pasarán por VaultPool. Al terminar, el PDF firmado podrá protegerse y distribuirse como una nueva versión.
Orden correcto para firmar

Un PDF debe editarse o rellenarse antes de aplicar una firma con certificado. Si se modifica después, la firma anterior deja de ser válida. VaultPool conservará siempre el original para evitar pérdidas.

Editor de texto y editor de código

La próxima versión prepara dos estilos de edición de texto: Bloc para notas rápidas y Documento para escritura cómoda. Guardar no modificará el archivo original, sino que generará una nueva copia con un nombre claro y fecha.

También se incorpora un editor de código con interfaz oscura, numeración de líneas, búsqueda, salto a línea, tabulación y guardado como nueva versión protegida.

Nombres claros para las nuevas versiones

Las copias generadas por edición utilizarán etiquetas comprensibles como editado, formulario rellenado, firma visual o firmado, acompañadas de fecha y hora.

Qué seguimos preparando

  • Más capacidades de Arcade para formatos compatibles y juegos que puedan ejecutarse legalmente desde el navegador.
  • Más formatos de documentos y edición avanzada.
  • Más opciones de vista previa y reproducción directamente desde carpetas protegidas.
Estado de esta información

Estas funciones corresponden a la próxima versión que está en desarrollo. La edición disponible públicamente en este momento continúa siendo la distribuida desde Microsoft Store.
