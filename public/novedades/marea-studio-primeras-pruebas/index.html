Las primeras canciones ya permiten juzgar el proyecto

La build portable interna de desarrollo 1.3 ha sido verificada con 40 pruebas y cinco generaciones reales. Además del funcionamiento técnico, esas canciones sirven para evaluar lo importante: composición, timbre, mezcla percibida y calidad de voz e instrumentos.

Primer balance: bastante satisfactorio

No significa que la calidad esté terminada. Significa que el flujo real de generación ya ofrece resultados suficientemente buenos como para entrar en una etapa de mejora auditiva más exigente.

Instrumental, letra de IA o tu propia letra

La creación se organiza alrededor de tres opciones claras: generar una pieza instrumental, pedir a la IA que escriba la letra a partir de la idea musical o conservar exactamente una letra escrita por el usuario.

Voz masculina o femenina. Español o inglés.

Los controles de voz e idioma se han reforzado para que lleguen al motor como instrucciones explícitas. Si el texto del prompt contradice la selección, la interfaz puede avisar en lugar de dejar que dos instrucciones compitan silenciosamente.

Más calidad musical, no una cifra más grande

El objetivo actual no es mejorar un archivo después de generarlo, sino conseguir una mejor generación desde el origen: guitarras, batería, bajo, sintetizadores y voz. También se ha preparado un modo XL de 64 pasos y opciones de mayor detalle, que emplean más cálculo para buscar mejores resultados.

Una interfaz mucho más clara

La pantalla de creación se está separando en tres áreas fáciles de entender: Idea musical, Voz y letra y Producción. Los parámetros más técnicos quedan fuera del camino principal. Tras generar, cada resultado muestra su canción y un botón claro para escucharla o pausarla; la última creación queda accesible también desde Biblioteca.

¿Se puede descargar Marea Studio?

La canción de prueba «Mi próxima marea» sí se puede escuchar y descargar libremente desde esta misma página. La aplicación Marea Studio todavía no: existe una portable de desarrollo para pruebas internas, pero no hay ninguna build pública para usuarios. Seguirá apareciendo como «Próximamente» hasta que haya una versión realmente preparada para compartir.

El proyecto ha seguido creciendo

Desde estas primeras pruebas, Marea ha avanzado hacia un Editor de pistas con frases musicales, audio importado y generación parcial con IA. Hemos abierto además un foro específico para recoger feedback de usuarios.
