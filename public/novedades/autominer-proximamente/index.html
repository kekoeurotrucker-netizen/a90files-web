AutoMiner: minería adaptativa pensada para cuidar el hardware

Estamos preparando AutoMiner para Windows: una aplicación que supervisa un minero externo y adapta su intensidad según la temperatura y la carga real del PC. Todavía no existe una versión pública para descargar.

Próximamente, pero todavía no publicado

AutoMiner sigue en desarrollo. Aún no hemos publicado ni subido una versión pública para Windows, así que por ahora no hay instalador ni descarga oficial. La idea es enseñar el proyecto antes de su primera versión pública y mantener el estado claro en todo momento.

La prioridad es el equipo, no exprimir el hashrate

El enfoque de AutoMiner es diferente al de un lanzador que simplemente mantiene la minería al máximo. El objetivo principal es proteger temperaturas, estabilidad y vida útil del hardware, adaptando la carga cuando el PC está haciendo otras cosas.

Qué estamos preparando

  • Modos OFF, ECO, BALANCED y AWAY.
  • Regulación adaptativa de la intensidad según temperatura y recursos disponibles.
  • Reducción automática de la carga cuando otras aplicaciones necesitan GPU, CPU o memoria.
  • Convivencia con tareas pesadas como edición de vídeo o herramientas de IA, reduciendo intensidad cuando haya margen en lugar de detenerse siempre.
  • Parada de seguridad cuando las condiciones térmicas o del sistema lo requieran.
  • Supervisión del proceso de minería, recuperación ante fallos y comportamiento conservador ante problemas de sensores.
  • Flujo previsto de trabajo: GPU → minero → pool → wallet.
Sin promesas de rentabilidad

AutoMiner automatiza y protege el proceso, pero no vamos a anunciar ganancias garantizadas. La rentabilidad depende de demasiados factores externos y puede cambiar.

También seguimos con Project Trucker / Logistic Trucker

En paralelo continúa la evolución del simulador logístico. El trabajo actual consiste en portar y reconstruir el sistema anterior 2D sobre una nueva base 3D, manteniendo la lógica de gestión, progresión y transporte que ya existía, pero trasladándola a un entorno preparado para carreteras, ciudades, carga, vehículos y navegación tridimensional.

La migración todavía está en desarrollo. Conservamos material visual de las pruebas del sistema anterior y lo iremos usando para enseñar la diferencia entre aquella etapa 2D y la nueva versión 3D a medida que el nuevo entorno esté listo para mostrarse.

Qué viene ahora

Seguiremos validando el funcionamiento real, la regulación de carga y las protecciones antes de considerar una primera publicación para Windows. Cuando exista una build pública lista para probar, lo anunciaremos en A 90 Files y en el hilo oficial del foro.
