Un clásico que queremos llevar a Windows

El objetivo de RoadTrip-ES es adaptar Road Trip Adventure (conocido también como Choro Q HG 2) para jugarlo en Windows, aprovechando el trabajo técnico de portabilidad existente y desarrollando la localización al español.

Queremos una experiencia sencilla: arrancar el juego, elegir idioma y disfrutar de la aventura sin tener que configurar herramientas complejas. Eso es la meta del proyecto, no una característica que anunciemos ya como terminada.

Las imágenes de esta página muestran el port de referencia utilizado para estudiar la adaptación; no son una demostración de RoadTrip-ES finalizado.

¿Qué estamos preparando?

01Un port para Windows a partir de una base técnica compatible.
02Textos y menús traducidos al español con posibilidad de elegir inglés.
03Pruebas de funcionamiento, controles, audio, gráficos y guardado.
04Un sistema de instalación simplificado, una vez completadas las comprobaciones técnicas y legales.

¿Cuándo se podrá jugar?

Próximamente es nuestra dirección, pero todavía no tenemos una fecha de lanzamiento confirmada. Tampoco existe una descarga pública de RoadTrip-ES en A 90 Files. Publicaremos avances verificables antes de anunciar una versión para usuarios.

¿Cómo funcionará la instalación?

La idea es preparar un port gratuito que pueda utilizar los archivos de una copia legítimamente obtenida por cada usuario, sin distribuir la imagen del disco ni los recursos comerciales originales. El procedimiento definitivo estará sujeto a pruebas, condiciones de las licencias y revisión de derechos.
