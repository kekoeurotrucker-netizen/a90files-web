Project Trucker 3D.
La nueva etapa de Logistic Trucker.

El proyecto está trasladando y reconstruyendo en 3D el sistema que anteriormente funcionaba en 2D. La intención es conservar la lógica de gestión, progresión y logística ya desarrollada mientras carreteras, ciudades, vehículos, carga y navegación pasan a una experiencia tridimensional.

TRANSICIÓN ACTUAL

Del sistema 2D a un mundo 3D

No se trata únicamente de cambiar la apariencia: los sistemas anteriores se están adaptando a una arquitectura preparada para un entorno tridimensional y una simulación más completa.

ESTADO

Desarrollo por fases

El proyecto continúa en pre-alpha. Cada bloque se valida antes de avanzar y todavía no hay una fecha pública de lanzamiento.

Transporte

Conducción, rutas y trabajo de transporte dentro del nuevo entorno 3D.

Logística

Carga, contratos y gestión seguirán formando parte del núcleo del proyecto.

Ciudades y carreteras

La nueva base está preparada para trasladar la experiencia a escenarios tridimensionales.

Progresión

Los sistemas de gestión y evolución se conservarán y ampliarán durante la migración.

Project Trucker 3D sigue en desarrollo y no tiene fecha de lanzamiento anunciada. Publicaremos capturas y avances a medida que la nueva etapa 3D esté lista para enseñarse.
